# every class read (`env::get` in Rust, `env.get` in TypeScript). Copy this
# file to .env.local, which .gitignore keeps out of git, and make it
# readable by you alone, since it may hold secrets:

#   cp .env.local.example .env.local && chmod 600 .env.local
#
# A deployed app takes the same names from its configuration (`config` in
# wasmkeep.toml) or its secrets (`wasmkeep secrets set`), never from here.
